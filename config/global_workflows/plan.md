# Plan Mode

Enter planning mode to safely research and design a strategy before any code modifications are made.

## Instructions
1. Perform thorough research using search and read-only tools to understand the task. Do not make code edits or run modifying commands.
2. Create or update the `implementation_plan.md` artifact under the artifact directory, detailing the findings, proposed changes, and a verification plan.
3. Stop and ask the user for explicit approval of the implementation plan before moving to the execution phase.
