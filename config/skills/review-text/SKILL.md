# Review Text Workflow

When the user invokes this workflow to review text, perform an analysis based on the following criteria:

1. **Logical errors:** Check for flaws in reasoning, contradictions, or fallacies within the text.
2. **Stylistic errors:** Identify issues related to the flow and readability of the text (e.g., wordiness, awkward phrasing, inconsistent tone or tense).
3. **Typographical and spelling errors:** Spot mistakes made during typing, such as accidental keystrokes, missing spaces, incorrect formatting, and correct any misspelled words.
4. **Semantic errors:** Look for words that are grammatically correct but convey the wrong meaning (e.g., using "affect" instead of "effect", or malapropisms).
5. **Grammar, syntax, and structural errors:** Identify standard grammatical mistakes and correct issues with how sentences are built (e.g., run-on sentences, sentence fragments, misplaced modifiers, subject-verb agreement).
6. **Punctuation errors:** Fix incorrect use or omission of punctuation marks (e.g., missing commas, misplaced apostrophes).

## Output Format

Present your findings clearly. Underneath each label defined above, list the errors found as bullet points. 
For each error:
- Quote the original text containing the error.
- Briefly explain the issue.
- Provide a suggested correction for that specific error.

At the end of your review, provide a suggested corrected version of the entire text with all errors fixed but nothing else changed.
