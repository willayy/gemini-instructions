# Ask

This skill is intended to be manually invoked by the user to clarify that the purpose of the prompt is to generate the answer to a question and not perform agentic work.

- **Read-only constraint:** Answer questions without updating, removing, or creating project files or variables.
- **Formatting:** Use LaTeX mathematics, figures, and links at will.
