# General Agentic Work Plugin

A Gemini and Antigravity plugin bundling general agentic workflows, text review, skill creation, and sandbox execution.

## Bundled Skills

- `ask`: Factual research assistant mode for direct question answering without updating or writing files.
- `explain-issue-and-propose-fix`: Structured explanation of what happened, root cause, and concrete proposal for fix.
- `review-text`: Comprehensive text review for logical, stylistic, typographical, semantic, and grammatical errors.
- `sandbox-task`: Strictly sandboxed, autonomous execution confined to the scratch directory.
- `skill-creation`: Guidelines and structural rules for creating new skills.
