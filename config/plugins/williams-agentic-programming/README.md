# Agentic Programming Plugin

A Gemini and Antigravity plugin bundling programming instructions, architectural patterns, and Git workflows.

## Bundled Skills

- `add-commit-push`: Make several different git adds, commits, and pushes with fitting messages.
- `agent-development-instructions`: Instructions and constraints for AI agents regarding testing, scripting, filesystem usage, and runtime permissions.
- `general-programming-instructions`: Language-agnostic coding standards, architecture rules, and design patterns.
- `git-instructions`: Conventional Commits rules, prefixes, and commit message constraints.
- `python-programming-instructions`: Python styling and design rules complementing PEP standards.
- `react-programming-instructions`: React and TypeScript guidelines utilizing MVVM, dependency injection, composition, and colocation.
- `relational-database-instructions`: Checklist for designing, altering, and validating relational databases.
